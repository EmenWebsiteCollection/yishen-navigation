# 多模态任务卡：创作者主页封面 / 默认视觉素材

> 交接流程：功能组（本卡）→ CGPT 组员（多模态）→ 回填 → 功能组接入验收。
> 使用说明：把下面的「任务卡」原样复制到 Issue / 聊天中发给 CGPT 组员；完成后让其贴回输出文件或链接，并 @ 功能组。

---

## 任务卡

**1. 目标**
为「依门」创作者主页制作一组默认视觉素材，供没有自传封面/头像的用户使用，并输出可替换的占位封面。

**2. 输入材料**
- 品牌名：依门（旧称「依神网站汇总」）
- 项目定位：创作者社区（小说/插画/游戏/音乐/摄影/AI 创作等）
- 主色调：金棕 `#9C6B2E`，背景米色 `#F3EAD8`（可参考现有主题 tokens.css）
- 字体方向：衬线中文（Noto Serif SC / 宋体系）为主，文艺、克制

**3. 约束**
- 封面尺寸：1280×360（约 3.5:1），PNG/JPG，≤500KB
- 默认头像：512×512，圆形可裁切，PNG，≤200KB
- 风格：简洁、有质感、避免廉价渐变和过多装饰；留出文字安全区
- 不出现未授权字体/素材；如用 AI 生成需保证无明确品牌商标

**4. 期望输出**
- 2 张封面（一张「默认创作者封面」、一张「空状态/占位」）+ 1 张默认头像
- 输出为可下载的文件链接或仓库路径

**5. 验收标准**
- [ ] 尺寸/格式/大小符合约束
- [ ] 视觉与金棕米色主题一致
- [ ] 文字安全区充足
- [ ] 无版权风险

**6. 回填要求**
- 完成后把文件链接 + 缩略图贴回，@ 功能组；功能组接入后做最终验收。
