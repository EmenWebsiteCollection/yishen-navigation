# UI.md

# 页面结构与交互说明

## 现有页面

- `/` 首页：Logo + 顶部导航（登录/注册/提交网站/个人中心）+ 高分作品轮播 + 网站导航列表（分页、点赞）。
- `/website/:id` 作品详情：大图、元信息、描述、点赞/收藏、评论（支持回复）、更新日志（有则展示）、编辑/删除（本人）。
- `/create` 新建作品：类型选择（网站需 URL 并自动截图；其他类型可选封面）、标题、描述、公开/私密。
- `/website/:id/edit` 编辑作品：类型、标题、URL、描述、图片/封面、状态、公开/私密、分组、更新日志。
- `/login` / `/register`：登录与注册（首页 Modal 内嵌）。

## 新增页面

### `/profile` 个人中心（需登录，匿名不可用）
- 顶部：统计卡（公开作品数 / 累计获赞 / 被收藏 / 作品评论）。
- Tab「我的作品」：分组筛选（全部/未分组/自定义组），作品行含封面、精选/私密/状态徽标、点赞数、操作（分配分组、设精选、公开/私密、编辑、删除），分页。
- Tab「我的收藏」：收藏的作品列表 + 取消收藏。
- Tab「设置」：头像、主页封面、个人介绍、擅长领域/常用工具/风格标签（逗号分隔）、当前项目 + 进度条、合作状态、商业委托、可提供服务、社交外链（每行 平台,链接）、个人网站链接、主页背景色/强调色；分组管理（创建/重命名/删除）。

### `/user/:id` 创作者主页（公开）
- 封面横幅 + 头像 + 用户名 + 介绍。
- 画像标签：擅长领域 / 常用工具 / 创作风格。
- 统计：作品数 / 累计获赞 / 被收藏 / 作品评论。
- 状态：合作状态、商业委托、可提供服务、当前项目 + 进度条。
- 外链：社交平台 + 个人网站/商店。
- 代表作品（精选横排）与完整作品集（按年份分组形成创作时间线）。
- 若该用户设置了装扮色（背景/强调色），本页应用其配色。
- 本人访问显示「编辑资料」入口。

## 入口与联动
- 首页卡片、高分轮播、评论区、详情页作者，均显示头像并链接到 `/user/:id`。
- 顶部导航登录用户显示「个人中心」→ `/profile`。

﻿### `/ideas` 想法集中营（公开）
- 顶部 PageHero + 搜索框 + 最新/最热切换 + 状态 Tab（全部/灵感/开发中/已实现/已关闭）+ 分类 chips + 「发布想法」按钮。
- IdeaCard：状态徽章 / 置顶标记 / 分类 / 标签 / 标题 / 描述摘要（2 行截断）/ 作者头像 / 👍·💬·⭐ 计数 / 相对时间；已实现卡片靠状态徽章高亮。
- 分页（上一页/下一页 + 页码信息）；空态引导「发布第一个想法」。

### `/ideas/new` 发布想法（需登录且非匿名）
- 必填仅 2 项：标题（≤80）+ 分类（8 类 chips）；描述（≤2000）、标签（≤10 个，逗号分隔）可选。
- 输入标题实时（400ms 防抖）提示相似想法（最多 3 条，点击跳转），防止重复发帖分裂票数。
- 匿名账号提示先登录，表单禁用。

### `/ideas/:id` 想法详情（公开）
- 头部：状态徽章 + 置顶 + 分类 + 标题 + 作者（头像/用户名，链到创作者主页）+ 发布时间 + 标签。
- 操作：👍 投票（一人一票，可取消）、⭐ 关注（收藏=关注，计数公开、列表私密）、💬 讨论数。
- 已实现回链：有关联作品时显示绿色横幅「🎉 已实现：作品「xxx」→ 去看看」。
- 作者/管理员：状态变更（自动写进展时间线，关闭必须写理由）+ 补充进展；「🚀 去实现这个想法」跳转 `/create?source_idea_id=...`。
- 管理员：合并重复想法面板（粘贴源想法 ID，投票/评论转移，双端留痕）。
- 进展时间线：状态变更 / 进展 / 合并三类条目按时间正序展示。
- 讨论：与作品详情页一致的评论树（回复/删除，级联删除由数据库处理）。

## 入口与联动（#12 追加）
- 顶部导航新增「想法集中营」→ `/ideas`。
- 首页高分轮播下方新增「想法集中营」入口横幅。
- 个人中心新增 Tab「我的想法」（我发布的 + 我关注的）。
- 作品详情若有 `source_idea_id`，顶部显示「孵化自想法：xxx」链接。
- 创作者主页统计卡新增：想法数 / 想法获赞 / 已实现数。

## 视觉规范
- 沿用 `src/styles/tokens.css` 的 CSS 变量主题体系（`--ym-*`），不引入新 UI 库。
- 新页面采用与现有页面一致的内联样式 + 主题变量写法；视觉细节归 UI 组，多模态素材走任务卡。

# Issue #39 新增页面与交互（v0.4）

### `/discover` 作品发现（公开）
- 「今天看点不一样的」每日随机：质量门槛（≥1 赞或编辑精选）+ 会话内去重 + 推荐语。
- 多入口 Tab：最新发布 / 本周新锐 / 编辑精选 / 小众宝藏 / 正在成长 / 零评论作品 / 关注动态（登录）/ 收藏偏好（登录）。
- rail 内作者去重（每人最多 2 件，防大账号霸屏）；「加载更多」继续翻页。
- 支持 `?tag=xxx` 标签筛选（详情页标签点击跳转）；空态正向文案（如零评论为空显示「大家都在被认真回应」）。

### `/work/:id/map` 灵感地图（公开）
- 轻量 SVG 节点图：中心作品 + 显式关系环（衍生/改编/同灵感/合作，橙色实线）+ 自动相似环（灰色虚线）。
- 节点可点击跳转对应作品；无关系时显示引导空态（补标签 / 作者声明关系）。

### 作品详情页（v0.4 增量）
- Meta 区：关注按钮（登录且非本人）、创作标签区（AI 徽章 / 创作类型 / 完成度 / 合作·二创·商用 / 受众 / 内容警告 / 可点击标签 / 风格·工具）。
- AI 参与程度为 unknown 时显示《AI 生成合成内容标识办法》风险提示。
- 媒体区：media_url 直链 → 内嵌 `<video>/<audio>` + 时间轴标记；video_url 外链保留跳转按钮。
- 评论区：反馈类型 chips（默认「单纯欣赏」）+ 局部批注工具栏（图片/文字/视频/音频/组件）+ 锚点摘要；每条评论显示类型徽章与锚点信息（文字批注含改版失效提示）。
- 评论质量评价（有帮助/有洞察/专业/表达友善）+ 作者「采纳这条建议」→「✓ 已被作者采纳」。
- 作品成长档案：版本快照卡片（第一版/修改版/最终版 + 变更点 + 采纳建议回链 + 采纳说明）。
- 管理员：编辑精选开关（底部操作区）。

### 个人中心 `/profile`（v0.4 增量）
- 统计卡下方新增「我的评论者信誉」卡：徽章（新面孔/热心评论者/策展人/评审者）+ 信誉分 + 采纳数 + 收到评价统计。不做公开排行榜。

### 创作标签体系（创建/编辑表单）
- AI 参与程度必填（默认「未知」）；其余标签/风格/工具（逗号分隔）、创作类型、完成度 0-100、受众、内容警告多选、合作/二创/商用开关均可选。
- 编辑页新增媒体文件上传（mp4/webm/mp3/ogg，视频≤100MB/音频≤30MB）→ 设为作品内嵌播放。

## 视觉规范（沿用）
- 全部沿用 `--ym-*` 主题变量 + 内联样式；灵感地图节点图/批注 pin 先灰盒，视觉细节交 UI 组。
- 空态/封面等视觉素材走多模态任务卡交 CGPT 组员产出，功能组接入验收（截图级）。
