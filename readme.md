## 🔄 协作开发流程

所有功能开发必须遵循以下标准化流程，确保代码质量和项目稳定性：

```
需求提出
   ↓
创建 Issue（包含需求描述、验收标准）
   ↓
分配负责人（由项目管理组指定）
   ↓
创建开发分支（命名规范：feat/xxx 或 fix/xxx）
   ↓
功能开发（遵循代码规范，编写单元测试）
   ↓
提交 Pull Request（关联 Issue，填写变更说明）
   ↓
代码审核（至少一位 Reviewer 批准）
   ↓
测试验证（由测试与产品组执行）
   ↓
合并到 main 分支
   ↓
Netlify 自动部署上线
```

## 📌 注意事项

- 所有 Issue 和 PR 必须使用英文或中文清晰描述，并关联对应的项目看板。
